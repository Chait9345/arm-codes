INTERFACING STEPPER MOTOR AND DC MOTOR
Aim: Assembly language programming to interface Stepper and DC motors
1. Program to rotate stepper motor anticlockwise (Full stepping with single coil energized
at a time). It is full stepping (step angle 1.80 per step). Note: Short JP13
O01 IOODIR EQU 0xE0028008 ;Address for configuring PortO as I/O
O02 IOOSET EQU OxE0028004 ;Register address for setting PortO pins
03 IOOCLR EQU OxE002800C -Register address for clearing PortO pins
04 AREA CHANG, CODE, READONLY
05 EXPORT main ;refer the line no 416 of startup.s file
06 _ main
07 ENTRY
08 LDR ri,=IOODIR ; load the address of the IODIR reg to R1
it) LDR r0,=OxFO00; To set P0.9 as output pin for buzzer
10 STR rO, [ri] ¢This configure P0.12-P0.15 as output pins
N LDR r2,=IOOCLR ; load the address of the IOCLR reg to R2
12 LDR r3,=IO0SET ; load the address of the IOSET reg to R23
13°58 LDR R5,=O0OX8000 ; Energise single coil at 42 time
14 BACK STR RO, [R3] ¢ Set all 4 pins to 1 to turnoff motor
15 STR RS, [R2] ; Clears one bit at a time to enable a coil(Active lov)
16 LDR R4,=Ox2FFF; Keep varying this value for different speed
17 delay SUBS R4,R4,#1;
18 BNE delay
19 MOV R5,R5,LSR #1; shift for energising next coil
20 CMP R5,0X800 ; Are all coils energised?
21 BNE BACK
22 BS
23 END
Note:
i. Full stepping can be achieved by energizing two adjacent coils at a time (step angle 1.8° per
step).
ii. Half stepping can be achieved by alternately energizing two coils at a time and then one coil
at a time (step angle 0.9° per step)
