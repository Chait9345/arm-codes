8.Program to find square of a decimal number (0 to 10) using lookup table
01 AREA SQUARE , CODE, READONLY
02 ENTRY ¢Mark first instruction to execute
03 START
04 LDR RO,=TABLE1 =; Load start address of Lookup table
05 LDR R1i,=INP ¢ Initialize value at 0x40000000
06 MOV R2,R1
07 LDR Ri, [R1] ; Load no whose square is to be find
os MOV R1,R1,LSL#0x2; Ri=Value at INPx4. to point at corresponding square
0g ADD RO,RO,R1 ; Load address of element in Lookup table
10 LDR R3, [RO] ¢ Get square of given no in R3
11 STR R3, [R2,#4]!
12 =S B s
13. ;Lookup table contains Squares of nos from 0 to 10
14 TABLE1 DCD 0,1,4,9,0x16,0x25,0x36,0x49,0x64,0x81,0x100;
15 AREA DATA1, DATA, READWRITE
16 INP DCD Oxo0045
7 END ; Mark end of file
